# 0.3.6 固件 3.13 连接兼容

验证日期：2026-10-12。构建使用 Java 25、Gradle Wrapper 9.8.1、IntelliJ Platform Gradle Plugin 2.19.0 和 IDEA 2026.2 SDK。

## 变更

用户的控制器固件为 3.13，旧版本的已识别固件检查仅接受 3.12。0.3.6 将连接版本集合扩展为 3.12 / 3.13，保留原有 3.12 行为及 0.3.5 的零值句柄修复。

- 通过 `#SI` 识别的主版本与次版本同时接受 `3.12`、`3.13`，包含 `3.12.01.00`、`3.13.01.00` 等补丁版本。
- 已识别的其他版本仍拒绝连接；错误消息给出接受的版本。测试另检查 `3.130` 不会被误当成 `3.13`。
- 设置页、工具窗口及插件说明同步显示 3.12 / 3.13。环境存储结构和文件映射不变。
- SDK C 库文件版本、固件版本和原生通信句柄仍分别处理。3.13 原生模拟场景覆盖 `7.2.0.0` C 库文件版本和零值 ETHERNET 句柄，并读取缓冲区状态。
- 语言资料库仍依据 ACSPL+ 3.12 手册，本次没有重新生成或扩充 3.13 语言符号。

## 验证

全部 **77 项测试通过**，失败、错误、跳过均为 0：语言编辑测试 33 项、控制器引擎/协议测试 25 项、IDE 集成测试 8 项、Windows 原生桥接测试 11 项。
