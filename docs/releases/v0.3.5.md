# ACSPL+ 0.3.5

修复 Windows ACS SDK 连接时误报 `ACS SDK error 0: ` 的问题。旧桥接把数值为 0 的有效通信句柄判为失败；现在按 `ACSC_INVALID (-1)` 判断，模拟器和 ETHERNET 的连接、后续操作及断开连接均接受零值句柄。

- 真正的连接失败及超时设置失败仍会被拒绝。错误日志显示 SDK 接口名称、错误码和说明；ETHERNET 打开失败包含目标地址和端口。
- 缺少 SDK 错误码或说明时明确提示，错误日志不再包含整段 PowerShell 调用堆栈。
- 74 项测试全部通过，包含 10 项 Windows 原生桥接测试；覆盖零值、非零值和 64 位句柄，以及打开失败、超时失败和断开连接。
- Plugin Verifier 对 IDEA、CLion、PyCharm、Rider 2026.2 的检查全部为 Compatible。

下载 `acspl-language-0.3.5.zip`，在 IDE 的 **Settings → Plugins → 齿轮 → Install Plugin from Disk** 中选择 ZIP 升级，按提示重启后重新连接。原 DLL 路径、连接参数和文件 → 缓冲区映射可继续使用。

桥接源码和演示脚本保持 ASCII。原生验证使用测试 DLL，未连接用户实际 SDK 或实体控制器；如果连接仍失败，请根据新的接口名称、目标地址/端口和错误码继续检查。详见仓库的控制器指南和 `docs/verification-0.3.5.md`。
