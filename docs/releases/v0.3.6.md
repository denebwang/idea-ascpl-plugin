# ACSPL+ 0.3.6

控制器连接检查新增固件 3.13 系列，同时保留 3.12 兼容性。接受 `3.12`、`3.13` 及其补丁版本，例如 `3.12.01.00`、`3.13.01.00`。

- 保留 0.3.5 的零值连接句柄修复，C 库文件版本与控制器固件版本继续独立处理。
- 已识别的其他固件版本仍拒绝连接，设置页、工具窗口及插件说明显示 3.12 / 3.13。
- 77 项测试全部通过，包含 11 项 Windows 原生桥接测试；覆盖 3.13 ETHERNET、零值句柄、C 库文件版本 `7.2.0.0` 和缓冲区状态读取。
- IDEA、CLion、PyCharm、Rider 2026.2 的 Plugin Verifier 检查全部为 Compatible。

下载 `acspl-language-0.3.6.zip`，在 **Settings → Plugins → 齿轮 → Install Plugin from Disk** 中选择 ZIP 升级，按提示重启后重新连接。原 SDK 路径、连接参数和文件映射可继续使用。

原生测试使用模拟 DLL；真实 SDK 和 3.13 控制器仍需联调。离线语言资料库继续依据 ACSPL+ 3.12 手册。详见控制器指南与 `docs/verification-0.3.6.md`。
