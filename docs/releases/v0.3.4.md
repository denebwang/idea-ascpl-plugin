# ACSPL+ 0.3.4

首次开源发布，为 JetBrains 2026.2 IDE 提供 ACSPL+ 3.12 脚本编辑支持，并包含 Windows 控制器开发环境预览功能。

- 语法高亮、GLOBAL/LOCAL 和用户函数颜色、行注释、补全及离线快速文档。
- 环境列表与表单设置，支持 SDK DLL 浏览、脚本文件选择和缓冲区映射。
- 修复将 C 库 DLL 文件版本与 ADK/固件版本直接比较的问题：`7.2.0.0` 不会再因不是 `3.12` 而被拒绝。保留 x64、所需导出接口及已识别控制器固件检查。
- 控制器预览功能支持下载编译、运行、行调试、只读变量查看和单缓冲区 Flash 保存；脚本源码必须为 ASCII。

支持平台构建 `262` 至 `262.*`。IDEA、CLion、PyCharm、Rider 的 Plugin Verifier 检查均为 Compatible；69 项测试通过，其中原生桥接测试使用测试 DLL。这不代表真实 ACS SDK、实体控制器或 Flash 断电保持已经完成验证。

下载下面 Assets 中的 `acspl-language-0.3.4.zip`，在 IDE 中打开 **Settings → Plugins → 齿轮 → Install Plugin from Disk**，选择 ZIP，按提示启用或重启。源码 ZIP 不是插件安装包。

控制器连接需要用户自行安装 Windows ACS ADK 及 x64 C 库，使用步骤和联调限制见仓库的 [控制器指南](https://github.com/denebwang/idea-ascpl-plugin/blob/v0.3.4/docs/controller.md)。源码采用 MIT 许可证，厂商 PDF、SDK DLL、IDE SDK 和控制器备份不随仓库或安装包分发。
