# 0.3.3 控制器设置表单

验证日期：2026-10-11。使用 Java 25、Gradle Wrapper 9.8.1、IntelliJ Platform Gradle Plugin 2.19.0 和 IDEA 2026.2 SDK。开发机未安装厂商 ACS SDK/ADK，控制器测试使用 Java 模拟传输和测试导出 C 库。

## 变更与原因

旧设置页的 `isModified()` 会结束表格单元格编辑；IDE 定期调用该方法检查修改，因此双击输入后可能自动退出编辑。

- 移除环境及映射表格，改为环境列表、映射列表与独立文本表单，单击选择后直接填写。
- 修改检测只读取草稿，不结束编辑、不更新文本、不切换选择或请求焦点。
- DLL 路径增加浏览按钮；脚本选择器限于项目内的 `.prg` / `.acspl` 文件，自动填写项目相对路径。
- 映射在所属环境下编辑，修改环境名称保留关联。原有配置格式、环境 ID、选定环境及映射保持兼容。
- 切换环境或映射保留未应用的输入，包括尚未填完的数字。Apply/OK 完成全部校验后才替换设置；校验失败保留草稿和原设置，Reset/取消放弃未应用的修改。
- 窄窗口保持字段和浏览按钮可见，列表按钮纵向排列；高度不足时使用垂直滚动。

设置页不会连接控制器或执行脚本。控制器 SDK 桥接、ASCII 源码要求及 Flash 保存行为没有变更。
